# Security Policy

## Supported versions

Only the latest `trunk` is supported. There are no tagged releases; fixes land
on `trunk`.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub private vulnerability reporting: open the
repository's **Security** tab and choose **Report a vulnerability**
(<https://github.com/mralaminahamed/flagcast/security/advisories/new>).

Include what you can: the affected service (`gateway`, `evaluator`, `ai`,
`mcp`, `console` or `infra`), steps to reproduce, and the impact you expect.
The maintainer, @mralaminahamed, will follow up in the advisory thread.
